# GAIA Drift-Gate has moved

Drift-Gate is now fully open source (Apache-2.0) and lives in **[SoundByGAIA/gaia](https://github.com/SoundByGAIA/gaia)** (`gaia-drift`), together with the scanner and `gaia-scrub`.

This repository previously described paid $19/$49 packages. They are no longer sold; everything is free, including `gaia-drift mock <service>`. Paid options are limited to support, custom rule packs and one-off security audits: https://soundbygaia.com
